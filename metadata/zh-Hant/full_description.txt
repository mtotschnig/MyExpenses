<b>開支助手</b>是您極具隱私保護的終極個人財務管理工具——以開源透明的方式，讓您全面掌控日常費用追蹤、預算規劃與投資組合管理。

<b>核心功能：</b>

• <b>日常費用與預算追蹤</b>：在手機或平板電腦上輕鬆監控收入與支出。建立預算、拆分交易（分拆帳目），並設定定期交易計劃。
• <b>投資組合與資產管理</b>：追蹤股票、加密貨幣或自訂資產組合，監控價格歷史，即時管理多貨幣投資。
• <b>銀行對接與對帳</b>：透過 FinTS 直接連接受支援的銀行，或根據銀行對帳單手動核對交易，精準掌控帳戶餘額。
• <b>智慧收據掃描 (OCR)</b>：使用先進的光學字元識別技術，自動從收據和發票照片中擷取交易詳情。
• <b>桌面 Web 介面</b>：在區域網路內透過任何 Web 瀏覽器存取並管理您的交易。
• <b>強大的數據分析</b>：利用可自訂的動態圖表，直觀檢視支出趨勢、分類占比圓餅圖及歷史報告。
• <b>靈活同步與資料掌控</b>：輕鬆匯出和匯入 QIF 與 CSV 格式資料。支援 WebDAV、Nextcloud、Google Drive、Dropbox 或 OneDrive 跨裝置無縫同步，並支援用戶端證書。
• <b>隱私與安全至上</b>：開源透明、支援密碼或生物識別解鎖保護，以及加密資料庫防護。

<b>解鎖高級功能：</b>

• <i>貢獻版金鑰 (Contrib Key)</i>：主要亮點包括解鎖無限帳戶、定期交易計劃、匯出 PDF 列表、分類占比圖表等。
• <i>延伸版金鑰 (Extended Key)</i>：包含貢獻版金鑰的所有功能，外加自動雲端同步和高級 CSV 匯入規則。
• <i>專業版金鑰 (Professional Key)</i>：包含延伸版金鑰的所有功能，外加投資組合追蹤、歷史圖表、預算監控、收據 OCR 掃描、桌面 Web 介面、直接銀行同步（德國）等。

<b>權限透明度：</b>

• <i>日曆</i>：定期交易計劃儲存在專用本地日曆或您指定的任何日曆中。
• <i>網際網路</i>：匿名使用統計（選填）、雲端同步與崩潰報告（選填）。
