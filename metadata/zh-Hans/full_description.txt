<b>开支助手</b>是您极具隐私保护的终极个人财务管理工具——以开源透明的方式，让您全面掌控日常费用跟踪、预算规划与投资组合管理。

<b>核心功能：</b>

• <b>日常费用与预算跟踪</b>：在手机或平板电脑上轻松监控收入与支出。创建预算、拆分交易（分拆账目），并设置定期交易计划。
• <b>投资组合与资产管理</b>：跟踪股票、加密货币或自定义资产组合，监控价格历史，实时管理多货币投资。
• <b>银行对接与对账</b>：通过 FinTS 直接连接受支持的银行，或根据银行对账单手动核对交易，精准掌控账户余额。
• <b>智能小票扫描 (OCR)</b>：使用先进的光学字符识别技术，自动从收据和发票照片中提取交易详情。
• <b>桌面 Web 界面</b>：在本地局域网内通过任何 Web 浏览器访问并管理您的交易。
• <b>强大的数据分析</b>：利用可自定义的动态图表，直观查看支出趋势、分类占比饼图及历史报告。
• <b>灵活同步与数据掌控</b>：轻松导出和导入 QIF 与 CSV 格式数据。支持 WebDAV、Nextcloud、Google Drive、Dropbox 或 OneDrive 跨设备无缝同步，并支持客户端证书。
• <b>隐私与安全至上</b>：开源透明、支持密码或生物识别锁屏保护，以及加密数据库防护。

<b>解锁高级功能：</b>

• <i>贡献版密钥(Contrib Key)</i>：主要亮点包括解锁无限账户、定期交易计划、导出 PDF 列表、分类占比图表等。
• <i>扩展版密钥</i>：包含贡献版密钥的所有功能，外加自动云端同步和高级 CSV 导入规则。
• <i>专业版密钥(Professional Key)</i>：包含扩展版密钥的所有功能，外加投资组合跟踪、历史图表、预算监控、小票 OCR 扫描、桌面 Web 界面、直接银行同步（德国）等。

<b>权限透明度：</b>

• <i>日历</i>：定期交易计划保存在专用本地日历或您指定的任何日历中。
• <i>互联网</i>：匿名使用统计（可选）、云端同步与崩溃报告（可选）。
